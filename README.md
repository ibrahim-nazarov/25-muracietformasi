# 25% ödəniş müraciəti portalı

Streamlit ilə hazırlanmış tələbə və tutor portalı. Məlumatlar Google Sheet-də, qəbzlər Google Drive-dadır.

## Fayllar
- `streamlit_app.py`: interfeys
- `sheets.py`: Google Sheets və Drive ilə işləyən məlumat qatı

## Quraşdırma
pip install -r requirements.txt

## İşə salma
streamlit run streamlit_app.py

## Konfiqurasiya
Açarlar və tutor məlumatları `.streamlit/secrets.toml` faylındadır. Bu fayl GitHub-a yüklənmir.
